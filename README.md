# 🇱🇰 Travel Explorer – Discover Sri Lanka

Travel Explorer is a simple and user-friendly tourism website designed to help users discover beautiful tourist destinations across Sri Lanka. It provides information about popular beaches, mountains, historical places, cities, and natural attractions.

The website offers an easy way to explore destinations, view photographs, search for places, and save favourite destinations for future reference.

## 🌍 Live Demo

[Visit Travel Explorer](https://iamnanthakishor.github.io/Travel-Explorer/)

## 📌 Project Overview

Sri Lanka is a beautiful island with many attractive tourist destinations. Travel Explorer was developed to showcase these destinations through a clean, modern, and responsive website.

Users can explore different locations, view destination details, search for specific places, and save their favourite destinations using the favourites feature.

## ✨ Features

- **Explore Destinations:** Discover popular tourist destinations across Sri Lanka.
- **Destination Categories:** Browse destinations by beaches, mountains, nature, cities, culture, history, and wildlife.
- **Search Functionality:** Quickly find destinations using the search bar.
- **Destination Details:** View photographs and descriptions of selected destinations.
- **Favourite Destinations:** Add or remove destinations from your favourites.
- **Local Storage:** Favourite destinations remain saved even after refreshing the website.
- **Responsive Design:** Access the website using desktop computers, tablets, and mobile devices.
- **Interactive Interface:** Enjoy a clean and user-friendly browsing experience.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Extract the downloaded project if necessary.
3. Open the `travel-explorer` folder.
4. Open `index.html` using your preferred web browser.
5. Start exploring Sri Lankan destinations!

No additional software or database setup is required.

## 💾 Data Storage

Travel Explorer uses the browser's Local Storage to save users' favourite destinations.

The website does not require a backend server or database. Favourite selections are stored locally in the user's browser.
